# ZX_devel_VM
Documenting and eventually automate the creation of a VM for developing in C and Z80 assembler. With the ZX Spectrum as target.

The VM is intented to be hosted on the notebook of someone interested in developing for ZX Spectrum. The ultimate goal is automating the configuration of the VM with ansible playbooks. 

+ [Hardware Spec](Hardware.md) and OS for the VM
+ [Software](Software.md) installed on the VM. The choises of software have influences from "21st&nbsp;Century&nbsp;C,&nbsp;2nd Edition" by Ben Klemens. Plus the needed software to compile z88dk
