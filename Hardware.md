# Hardware & OS specs
A development environment for ZX does not need to be a big iron. 
+ 2 Cores / 2 CPU
+ 2 GB RAM and 4 GB of SWAP
+ 25 GB Disk
  + /boot/efi *512 MiB*
  + /boot *1 GiB*
  + Logical Volume *22 GiB, leave some unused space* 
    + / *18 GiB*
    + SWAP  *4 GiB*
+ 1 Network Interface
+ OS **Ubuntu Server 24.04 LTS**


*Might be interesting to do an unattended installation*
